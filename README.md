# 🌌 Virtual Solar System

An interactive **Virtual Solar System** built using **HTML, CSS, and JavaScript**.  
This project visualizes the solar system in both **2D and 3D views**, allowing users to explore planetary motion and customize key parameters like size, distance, and speed.

---

## 🚀 Features

- 🌍 **2D & 3D View Modes**  
  Switch between flat (2D) and immersive (3D) representations of the solar system.

- 🪐 **Interactive Planets**  
  View and adjust:
  - Planet size  
  - Distance from the sun  
  - Orbital speed  

- 🎛️ **Dynamic Controls**  
  Modify simulation parameters in real time.

- 🔄 **Animated Orbits**  
  Smooth orbital motion of planets around the sun.

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the application  
- **CSS3** – Styling and layout  
- **JavaScript (Vanilla JS)** – Logic and interactivity
